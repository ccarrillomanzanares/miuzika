Flow 1 · open and play

From disk to speakers: 20 steps. What breaks here is a missing WAV, an .sf2 that will not load or an empty project.

Flow 2 · one agent turn

19 steps and a loop. Here are the gates that keep the model from breaking the engine and the cutoffs that keep a turn from eating the session.

#stepwhat it does exactlyif it fails / branch
1you type and press Enterchat.ts → onSend → responderAlUsuario()The chat starts empty: its memory is agente.json, from the project.
2is a turn in progress?one turn at a timeOne turn at a time; the heartbeat shows "thinking · N s · N tokens".
3GET /api/manifiestoregenerates signatures with ast: 8.949 characters, 7 modulesIf /api/manifiesto fails, the turn continues with the basic prompt.
4system promptliteral with fingerprint + folder + manifest + agente.json (11.939 chars)It goes from 2.890 to 11.939 characters: literal + folder + manifest + memory.
5POST /api/llm (SSE)180 s limit · 32.768 tokens · progress every 700 msload = provider loading (0 tokens in 250 ms), not a lack of context.
6proxy + .env keythe key does not enter the client bundleThe key lives in the .env and never enters the client bundle.
7finish_reason?load · sin_salida · empty · stopsin_salida is retried without reasoning; empty: 5 retries (1-2-4-8-16 s) + 1 resumption.
8does it request tools?tool_calls in orderIf it requests no tool, that response is the turn's final one.
9ejecutarHerramienta()17 tools · own timeout · turn AbortSignalOne by one, in order, with their own timeout and the turn's AbortSignal.
10does the tool touch the project?7 of the 17The 7 that change the project do so in the tab: it owns the master.
11op in the tabenters the history, is undone with Ctrl+Z, the tab is the only one that writes the masterIt enters the history, is undone with Ctrl+Z and saves itself.
12gates409 if it redefines the engine or is patch*.py · 413 if >8 MB · 409 if numpy on LambdaThe smoke test imports the engine and renders a kick: if it fails, the change is reverted.
13run/python | run/lambdacwd = project folder · PYTHONPATH = codigo/ · GPU: scp + sshWithout an explicit destination the panel selector is used; the 409 avoids paying GPU for CPU.
14runs and writes to salida/returns escritos: only what changed in the projectWriting to codigo/ regenerates the manifest with ast, without running anything.
15result → model>4.000 characters: head + tail and the rest to _salidas/Above 4.000 characters: head + tail and the rest to _salidas/.
16are there steps left?maximum 12Cutoffs: 3 identical failures · 3 writes without running · 12 steps.
17final responsebubble in the chat + meta line (steps, tools, ms, model)Bubble + meta line: steps, tools, time and model.
18agregarTurno() → agente.json8 full turns + rolling summary of 1.800 characters8 full turns and a rolling summary of 1.800 characters.
19turn closedthe disk is the memory; the next request reads it from thereThe disk is the project's memory: the next request reads it from there.
Turn cutoffs: 3 identical failures in a row · 3 writes without running · 12 steps. An empty response is retried 5 times (1-2-4-8-16 s) and then one automatic resumption.
