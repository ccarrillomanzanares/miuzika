Un turno, de principio a fin

  1. chat.tssubmit → onSend → main.responderAlUsuario
  2. main.tspide /api/manifiesto y rehace el prompt: literal con huella + carpeta + manifiesto + memoria del proyecto
  3. main.tslatido de 1 s y burbuja «pensando · N s · N tokens» en el chat
  4. agent.tsbucle de hasta 12 pasos; cada paso es una llamada SSE al modelo
  5. llm.tsload → calienta con 1 token · sin_salida → repite sin razonar
  6. tools.tsejecuta cada herramienta pedida y le devuelve el texto al modelo
  7. servidorconfina, escribe/ejecuta, devuelve {ok, codigo, salida, errores, escritos}
  8. main.tsal cerrar: burbuja final + «✓ pasos · herramientas» + turno a agente.json
