A turn, from start to finish

  1. chat.tssubmit → onSend → main.responderAlUsuario
  2. main.tsrequests /api/manifiesto and rebuilds the prompt: literal with fingerprint + folder + manifest + project memory
  3. main.ts1 s heartbeat and "thinking · N s · N tokens" bubble in the chat
  4. agent.tsloop of up to 12 steps; each step is an SSE call to the model
  5. llm.tsload → warms up with 1 token · sin_salida → repeats without reasoning
  6. tools.tsruns each requested tool and returns the text to the model
  7. serverconfines, writes/runs, returns {ok, codigo, salida, errores, escritos}
  8. main.tson close: final bubble + "✓ steps · tools" + turn to agente.json
