A studio that listens.

miuzika is a DAW in your browser with an agent that composes, arranges and produces with you. Talk to it in your own language and it writes straight into the project: notes, chords, drums, effects and mix.

What it does

A full studio in a browser tab, plus a partner who understands music and can work on every part of the project.

Composes and arranges

Progressions, melodies, bass lines and drums built on real music theory. Ask for a change in words and it applies it to what is already there.

A real DAW

Timeline, piano roll, drum grid, SoundFonts and effects, running on openDAW's audio engine compiled to WebAssembly.

Produces and mixes

Sets levels, panning and effects on every track and the master, and exports to WAV or MIDI.

Sounds from words

Searches a CC0 library of more than 4,000 samples (VCSL), or creates sounds from a description.

Generative patterns

Write a Strudel pattern and it lands in the project as an audio track, bar by bar.

Synthesis in Python

When synthesized audio is needed, the agent runs numpy code on your machine, or torch on a cloud GPU.

How it works

The agent doesn't generate a finished audio file: it edits the project the way you would, with operations you can see, undo and tweak.

You talk to it

In any language, from the panel on the right. It answers in yours.

It reads the project

Tracks, key, bars, mix: it has the full context before touching anything.

It writes with ops

Transactional, validated changes. If something doesn't fit, nothing is half-applied.

You hear it

openDAW plays it right away. Anything you don't like can be undone or asked for differently.

Where it stands

Today miuzika runs locally, on the user's own computer. There is no online version or user accounts yet.

Working now

  • Projects with autosave; open audio, MIDI and projects by dragging them in
  • Agent with per-project memory and several model providers
  • VCSL library and SFZ-to-SoundFont instrument conversion
  • Export to WAV and MIDI
  • Interface in English and Spanish

Not yet

  • A hosted version: it starts with npm run dev
  • Buses and automation
  • Time signatures other than 4/4 in the pattern engine
  • Track effects on audio longer than 30 s
